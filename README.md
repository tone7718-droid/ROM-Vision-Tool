# ROM Vision Tool

카메라 영상의 2D 관절 좌표로 움직임 범위를 측정하는 **브라우저 프로토타입 v0.6**입니다. 임상 정확도는 검증되지 않았습니다.

## 실행

정적 파일을 HTTPS로 호스팅하거나 로컬 서버에서 실행합니다. `file://`로 열면 ES 모듈과 카메라 접근이 제한될 수 있습니다.

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 열고 카메라 권한을 허용하세요. 시작 시 MediaPipe 모델·WASM을 인터넷에서 내려받습니다. GPU 초기화에 실패하면 CPU로 다시 시도합니다. 지원 여부와 속도는 브라우저·기기에 따라 다릅니다.

## 사용 순서

1. 환자 식별번호(실명 대신 내부 번호 권장), 관절·좌우, 자세, 능동/수동 방식과 개별 목표를 설정합니다. 기본 목표는 편의를 위한 예시이며 정상 판정 기준이 아닙니다.
2. 무릎·팔꿈치·고관절 굴곡은 측면, 어깨 외전은 정면에서 촬영합니다. 측정할 세 관절점과 양쪽 어깨·고관절이 화면 안에 보여야 합니다.
3. 카메라를 시작합니다. 측정 중에는 조건이 잠겨 있습니다. 조건을 바꾸려면 카메라를 중지하세요.
4. 허용되는 두 끝범위에서 각각 **0.6초 이상** 유지합니다. 연속된 유효 프레임에서 각도 변화가 4° 이내인 끝범위의 중앙값을 기록합니다. 5° 이상의 움직인 범위가 있어야 저장할 수 있습니다.
5. 저장 후 같은 환자·관절·자세·방식·목표의 기록끼리 추세를 비교합니다. 작은 변화가 임상적 변화인지는 이 도구만으로 판정할 수 없습니다.

카메라 중지는 현재 측정값을 보존하고 영상 트랙·모델을 해제합니다. 화면을 벗어나도 카메라가 중지됩니다. 전후면 전환은 브라우저에 해당 카메라를 요청하며, 기기가 지원하지 않으면 다른 카메라가 선택될 수 있습니다. 전환 시 확인 후 현재 측정을 초기화합니다. 거울 화면은 표시만 뒤집으며 좌우 선택은 **피사체 기준**입니다.

## 각도 정의와 측정 품질

- 정규화 좌표를 영상의 실제 가로·세로 픽셀 좌표로 바꾼 뒤 세 점의 내각을 계산합니다. 가로세로 비율 때문에 발생하던 계산 왜곡을 보정합니다.
- 무릎·팔꿈치·고관절 굴곡각은 `180° − 내각`, 어깨 외전각은 몸통–위팔 내각입니다.
- 최소 측정각, 최대 측정각, 움직인 범위(`최대 − 최소`)를 별도로 표시합니다. 무릎·팔꿈치의 최소 굴곡각을 신전 제한 참고값으로 표시하지만 **과신전 방향은 구분하지 못합니다**.
- 어깨각은 견갑골과 몸통 움직임을 분리하지 못하며, 고관절각은 골반이 아닌 몸통을 기준으로 한 근사값입니다.
- 관절 가시성 0.65 미만, 화면 밖 좌표, 촬영 방향 경고가 있으면 기록 누적을 중단하고 필터를 초기화합니다. 추적 공백과 급격한 각도 변화도 다시 확인합니다. 이 문턱값은 임상 검증된 정확도 기준이 아닙니다.
- 몸통 기울임 신호는 서기·앉기의 어깨 외전과 고관절 굴곡에서만 사용합니다. 다른 관절·자세는 `null`(미지원)로 저장합니다. 신호는 임상적인 보상 판정이 아니며, 표시 중 측정값은 포함하고 유효 프레임 중 신호 비율을 기록합니다. 어깨 으쓱이나 골반 보상을 정확히 판별하지 않습니다.
- 누운 자세에서도 영상 좌표 계산은 가능하지만 가림·촬영 운동면 등의 영향이 큽니다. 자세 선택은 측정 조건 기록용이며 자세별 정확도를 보증하지 않습니다.

통증·수술 후 제한이 있다면 담당 치료사가 정한 범위 안에서 측정하세요. 자동으로 더 깊게 움직이거나 끝범위 유지 시간을 늘리라고 권하지 않습니다.

## 저장·백업·복원

- 측정 기록은 해당 브라우저의 `localStorage`에 저장됩니다. 다른 기기나 브라우저에는 자동으로 공유되지 않습니다. 브라우저 데이터 삭제·사생활 보호 모드 종료 시 사라질 수 있으므로 **JSON 백업을 별도로 보관**하세요.
- 저장 실패 시 성공 메시지를 표시하거나 현재 측정값을 초기화하지 않습니다. 기존 저장 데이터가 손상되었으면 빈 기록으로 덮어쓰지 않습니다.
- CSV는 전체 기록과 환자 번호·측정 조건을 포함합니다. 문자열을 이스케이프하고 스프레드시트 수식으로 해석될 수 있는 시작 문자를 보호합니다. CSV에는 복원에 필요한 모든 정보가 포함되지 않으므로 복원은 JSON을 사용하세요.
- JSON 복원은 10MB/10,000개 이하의 v2 형식을 검증하고 기존 기록에 병합합니다. 같은 ID는 중복 추가하지 않으며, 내용이 충돌하면 전체 복원을 중단합니다. 복원 전 확인을 받습니다.
- 기존 `romvision_records_v1`의 내각 기록은 원본을 삭제하지 않고 읽습니다. v2 첫 저장 시 기존 기록도 포함합니다. 측정 방식과 환자 정보가 없는 기존 기록은 **새 임상각 추세에서 제외**하고 JSON/CSV에 보존합니다.
- 기록 삭제는 확인 후 실행합니다. 여러 탭의 변경 알림을 받아 화면을 갱신하지만 다중 사용자 동시 편집이나 원자적 동시 쓰기는 지원하지 않습니다. 기록 작업은 한 탭에서 하세요.

## 실제 기술 구성

- `index.html`: 한국어 화면과 스타일
- `app.js`: 카메라 제어, 시각화, 기록·내보내기·복원 및 규칙 기반 요약
- `core.js`: 각도 계산, 유효 프레임·끝범위 관리, 기록 검증·변환
- MediaPipe Tasks Vision 0.10.14 / Pose Landmarker Full: 기기 내 포즈 추정
- 별도 서버·API 키·React Native·FastAPI·Firebase·외부 AI 요약 API는 사용하지 않습니다.

영상과 측정 기록을 외부로 보내는 코드는 없습니다. 단, MediaPipe 코드·WASM은 jsDelivr, 모델은 Google Storage, 글꼴은 Google Fonts에서 불러오므로 시작에는 인터넷이 필요합니다. 완전한 오프라인 배포·암호화 저장·사용자 인증·임상 정확도 검증은 구현되지 않았습니다.

## 검증

Node.js 22 이상에서 외부 npm 패키지 설치 없이 실행합니다.

```sh
npm run check
npm test
```

테스트는 화면 비율 보정, 관절별 각도, 순간 오인식, 추적 소실, 잘못된 촬영 방향, 저장 실패 후 값 보존, 기존 기록 보존, 환자별 비교 격리, 백업 검증·병합 및 CSV를 확인합니다. GitHub Actions에서도 구문 검사와 테스트를 실행합니다. 실측 정확도와 iOS/Android 카메라 동작은 별도로 실제 기기에서 확인해야 합니다.
